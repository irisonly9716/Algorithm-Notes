# How do I learn algorithm

This repo is my daily algorithm practice, and the method behind it.

## My method

1. **Build the foundation with CS50.** Before the semester started, I self-studied CS50. I took notes locally and explained each concept back in my own words.
2. **Practice on LeetCode.** After CS50, I started solving LeetCode problems. Every problem gets its own notebook entry, kept locally.
3. **Review with the memory curve.** Every day I practice again on a spaced-repetition schedule (the forgetting curve): problems I solved recently come back soon, and older ones come back at longer intervals.
4. **Commit to GitHub.** I commit my solutions here, so the commit history is a record of daily practice.
